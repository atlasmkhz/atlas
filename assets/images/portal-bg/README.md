# 포털 대표이미지 (배경) — 주간 로테이션

이 폴더에 사진을 **portal-bg-1.jpg ~ portal-bg-5.jpg** 이름으로 5장 넣으면
portal.js가 ISO 주차(월요일 00:00 KST 기준) 기준으로 자동으로 순환합니다.

- 1번은 기존에 쓰던 위성 야경 사진(portal-bg-v2.jpg)을 그대로 복사해뒀습니다.
  나머지 2~5번을 채워 넣어주시면 됩니다.
- 파일명은 반드시 `portal-bg-1.jpg` ~ `portal-bg-5.jpg` (숫자, 소문자 jpg)로
  맞춰주세요. 확장자가 다르면(.jpeg, .png 등) 안 뜹니다.
- 이미지 규격: 기존 사진(portal-bg-v2.jpg) 기준으로 맞추면 톤이 자연스럽게
  이어집니다 — 가로가 넓은 와이드 이미지, 좌상단(히어로 텍스트 영역)이
  너무 밝지 않은 사진이 좋습니다. (지도 위에 얹히는 배경이라 텍스트
  가독성을 위해 CSS에서 어둡게 오버레이를 씌우고 있습니다.)
- 사진을 5장이 아니라 10장으로 늘리고 싶으시면, js/portal.js에서
  `PORTAL_BG_COUNT` 값을 5 → 10으로 바꾸고 portal-bg-6.jpg ~
  portal-bg-10.jpg를 추가로 넣으시면 됩니다.
- 만약 특정 주차에 해당 파일이 없으면 사이트가 깨지지 않고 기존
  배경색(어두운 남색)으로 자연스럽게 대체됩니다 — 안전장치입니다.
