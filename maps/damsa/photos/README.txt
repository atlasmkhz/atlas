■ 자동 동기화 (권장)

  export DATA_GO_KR_KEY="data.go.kr에서 받은 일반 인증키"
  pip3 install requests pillow
  python3 build/sync_photos.py --dry-run   # 무엇을 받을지 먼저 확인
  python3 build/sync_photos.py             # 실제 동기화

  받아온 사진은 리사이즈·압축까지 끝내 아래 파일명으로 저장되고,
  themes.js의 credit 칸도 자동으로 채워집니다.

  ★ 확신이 없으면 붙이지 않습니다. 추측해서 채우지 않습니다.
    빈 자리는 photo_audit.md에 이유와 함께 남으니, 그 목록만
    직접 채우시면 됩니다.

  팩트체크는 photo_audit.md의 「카드 이름 vs 원본 제목」 두 열만
  나란히 읽으시면 됩니다. 어긋나면 그 파일을 지우고 직접 넣으세요.

■ 직접 넣으실 때 — 아래 이름 그대로 넣으면 끝입니다.
  코드는 손댈 필요 없습니다. 파일이 없는 동안에는 카드 상단이
  얇은 "사진 준비 중" 띠로 접히고, 파일을 넣으면 그 자리에
  사진이 나타납니다.

■ 규격 권장

  가로:세로 16:9 (카드가 16:9로 잘라 씁니다)
  가로 1200~1600px 정도면 충분합니다. 그 이상은 모바일에서
  로딩만 느려집니다.
  JPG, 장당 200~400KB 목표로 압축하세요.

■ 출처 — 저작권 안전한 순서

  1) 포토코리아  phoko.visitkorea.or.kr  (한국관광공사)
     10만여 장, 공공누리 제1유형. 상업적 이용·웹 서비스 모두 가능해서
     ATLAS에 가장 적합합니다. 여기서 먼저 찾으세요.
     · 공공데이터포털 API도 있습니다: 한국관광공사_관광사진 정보 (15101914)
       촬영지·촬영자·웹용 이미지 URL을 받아올 수 있어, 나중에 테마가
       늘면 자동화가 가능합니다.

  2) 국가유산포털  heritage.go.kr
     검색 필터에 [매체유형: 사진] + [공공누리: 제1유형]이 있습니다.
     반드시 제1유형만 거르세요. 지정 유산(부근리 지석묘·핑매바위 등)은
     여기가 화질이 가장 좋습니다.

  3) 지자체 홈페이지 (강화군·고창군·화순군)
     화질은 좋지만 공공누리 표기가 없는 경우가 많습니다. 표기가 없는
     자료는 담당자 사전 협의가 필요합니다. 급하지 않으면 1)·2)로
     먼저 채우는 편이 안전합니다.

■ 출처 표기가 필요한 사진

  data/themes.js의 해당 place > photo > credit 칸에 적으면
  캡션 아래에 작게 표시됩니다.

    credit: 'ⓒ한국관광공사 포토코리아 – 촬영자명'
    credit: '국가유산청 국가유산포털 (공공누리 제1유형)'

  공공누리 제1유형은 출처표시가 조건이므로, 이 칸을 비워두지 마세요.

■ 사진을 직접 찍으신 경우

  credit는 비워두거나 'ⓒ MKHZ' 로 적으면 됩니다.
  직접 촬영분이 가장 좋습니다 — 다른 어떤 사이트에도 없는 컷이
  ATLAS 답사의 차별점이 됩니다.
