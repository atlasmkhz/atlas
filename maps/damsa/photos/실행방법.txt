답사 사진 동기화 — 실행 순서
════════════════════════════════════════════════════════════════

Claude는 이 스크립트를 대신 실행할 수 없습니다.
  · 샌드박스 네트워크가 data.go.kr·포토코리아·커먼즈·국가유산포털을
    전부 차단합니다(프록시가 host_not_allowed로 거부).
  · TourAPI와 포토코리아는 왕두목님 개인 인증키가 필요합니다.

그래서 아래를 맥북 터미널에서 직접 돌리셔야 합니다. 3~5분입니다.


────────────────────────────────────────────────────────────────
0단계 — 인증키 없이 먼저 돌려보기  (준비물 없음, 30초)
────────────────────────────────────────────────────────────────

  cd ~/내려받은_atlas_폴더
  pip3 install requests pillow
  python3 build/sync_photos.py --dry-run

  인증키가 없으면 위키미디어 커먼즈만 씁니다. 커먼즈에도 강화 부근리
  지석묘·고창·화순 고인돌 사진이 있으니, 몇 장은 이 단계에서 이미
  채워집니다. 무엇이 잡히는지 먼저 눈으로 보세요.

  ※ --dry-run은 내려받지 않고 판정만 합니다. 확인 후 --dry-run을 떼고
    다시 돌리면 실제로 저장됩니다.


────────────────────────────────────────────────────────────────
1단계 — 인증키 발급  (한 번만, 5분)
────────────────────────────────────────────────────────────────

  포토코리아·TourAPI를 쓰면 후보가 훨씬 많아지고, 촬영자 정보가 와서
  credit이 자동으로 채워집니다. 공공누리 제1유형이라 상업적 이용도
  가능합니다.

  1) https://www.data.go.kr 회원가입
  2) "한국관광공사_국문 관광정보 서비스" 검색 → [활용신청]
     "한국관광공사_관광사진 정보"  검색 → [활용신청]
     → 개발계정은 자동승인입니다. 즉시 됩니다.
  3) 마이페이지 → 데이터활용 → 오픈API → 인증키 발급현황
     → "일반 인증키(Encoding)" 복사

  ※ 신청 직후 1시간쯤은 키가 활성화되지 않을 수 있습니다.
    401/SERVICE_KEY_IS_NOT_REGISTERED가 나오면 조금 기다리세요.


────────────────────────────────────────────────────────────────
2단계 — 실행
────────────────────────────────────────────────────────────────

  export DATA_GO_KR_KEY="복사한_인증키"

  python3 build/sync_photos.py --dry-run    # 무엇이 붙을지 확인
  python3 build/sync_photos.py              # 실제 저장

  결과물:
    maps/damsa/photos/*.jpg              사진 (1600px, 압축 완료)
    maps/damsa/photos/photo_audit.md     ★ 팩트체크용 표
    maps/damsa/photos/photo_sources.json 출처·라이선스 전체 기록
    maps/damsa/data/themes.js            credit 칸 자동 기입


────────────────────────────────────────────────────────────────
3단계 — 팩트체크  (5분)
────────────────────────────────────────────────────────────────

  photo_audit.md 를 열어서 두 열만 나란히 읽으세요.

      | 카드 이름 | 원본 제목 |

  이 둘이 가리키는 곳이 다르면 매칭 오류입니다. 해당 jpg를 지우고
  직접 넣으시면 됩니다(카드는 파일이 없으면 '사진 준비 중' 띠로
  접히므로 깨지지 않습니다).

  「붙이지 않은 자리」 절도 함께 보세요. 확신이 부족해 일부러 비운
  곳이고, 탈락 후보와 점수가 적혀 있습니다. 후보가 실은 맞는
  사진이었다면 그 URL에서 직접 받아 넣으시면 됩니다.

  credit 열이 "수동 필요"인 항목은 themes.js의 해당 photo.credit에
  직접 적어주세요. 공공누리 제1유형은 출처표시가 의무입니다.


────────────────────────────────────────────────────────────────
문제가 생기면
────────────────────────────────────────────────────────────────

  python3 build/sync_photos.py --debug --dry-run 2>&1 | tee photo_log.txt

  --debug는 API 원문 응답을 그대로 출력합니다. 이 로그를 붙여주시면
  한 번에 고칠 수 있습니다.

  특히 이것이 가장 가능성 높은 실패 지점입니다:
    TourAPI는 버전이 오르며 오퍼레이션 이름이 바뀌어 왔습니다
    (searchKeyword1 → searchKeyword2 → …). 지금 스크립트는
    KorService2 / searchKeyword2 / detailImage2 를 씁니다.
    404나 빈 응답이 오면 이 이름을 맞춰야 합니다.
    Claude가 실제 API로 검증하지 못한 유일한 부분입니다.

  매칭 로직 자체는 네트워크 없이 검증됐습니다:
    python3 build/sync_photos.py --self-test
